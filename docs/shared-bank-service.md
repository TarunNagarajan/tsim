# Shared bank service and common LSU

`execution-report --memory-config examples/sm_memory.json --shared-config examples/sm_shared.json` routes actual captured global and shared accesses through asynchronous services. Global sectors retain the existing cache, miss, writeback and backing queues. Shared traffic uses finite per-SM ingress storage, 32 bank queues, bank initiation ports and completion slots. A shared instruction completes after its last bank job and configured response transmission. RAW/WAW dependencies and CTA pre-arrival memory prefixes use that completion; block resources remain resident until all instruction and phase tails retire.

The [CUDA 12.6.3 programming guide](https://docs.nvidia.com/cuda/archive/12.6.3/cuda-c-programming-guide/index.html#shared-memory-5-x) specifies 32 banks, successive 32-bit words in successive banks, and same-word broadcasts. The model splits each recorded byte span into word fragments, preserving lane identity, vector element and byte masks. Ordinary same-word traffic becomes one logical word job. Byte, halfword, aligned scalar 32/64-bit and complete aligned v2/v4 layouts retain all their word work. The standalone component also accepts naturally aligned 16-byte spans, but the current validated capture contract admits only 1/2/4/8-byte elements; 128-bit scalar capture is not established. Wide PTX may lower to multiple SASS operations; these jobs do **not** predict physical instruction splitting, 128-byte transactions or measured conflict penalties. Overlapping store byte ownership is reported without selecting a winning lane.

Scalar 32/64-bit shared `atom` and `red` requests retain one job per captured update. Joint bank reservation and CTA-owned word locks serialize overlapping modeled atomic updates until completion; independent words can overlap subject to finite bank slots. Functional values come from the CPU interpreter. The timing service carries no data values, coherence state or scoped weak-memory outcomes. Its supported opcode spelling is explicit: default shared/generic load/store and scalar atomic forms; acquire/release, volatile, explicit scope, cluster addressing and undeclared cache hints require further models. Captured cluster-owner bits are rejected instead of becoming invented local bank offsets.

A generic PTX instruction can address global memory in some lanes and shared memory in others. Admission preflights every typed fragment before reserving anything. One common LSU slot remains occupied until the last fragment returns. The common capacity follows the global LSU configuration when enabled, otherwise the shared ingress capacity; initiation spacing uses the maximum interval of participating routes. The provider capacities remain independently enforced. This port-sharing rule is an explicit synthetic assumption. Register readiness, CTA releases and resident tails wait for the joined response. Global acknowledgement may precede terminal dirty backing writes, which still extend the launch boundary.

Sequential launches start with cold global caches and no live reservations, while common ingress, global memory, shared ingress and bank deadlines persist independently. Every queue and slot reservation has an ownership ledger; every logical word job has exact readiness, issue and completion timestamps. The independent references rebuild jobs from byte spans without calling the service's topology helper, compare routed payloads directly with original captured events, and audit FIFO storage, bounded capacities, bank bandwidth, multiword atomic exclusion, response joins, cross-launch deadlines and resident/CTA lifetimes. Corrupted ledgers, masks, routes, deadlines, completion times and peaks must fail the audits.

`tests/conformance/shared_bank_timing.cu` checks vector4, byte, halfword, scalar64, broadcast and shared atomic32/64 results, mixed generic loads and two CTA handoffs against 2,688 host calculations per run. Conformance executes both A100/H100 profiles and deterministic/random/adversarial scheduling with four CPU workers, then audits default, constrained queue/slot and two-SM timing configurations. The proof is recorded in [shared-bank-conformance.json](shared-bank-conformance.json); the broader regression remains [execution-conformance.json](execution-conformance.json). Queue dimensions, arbitration, word merging across wide PTX, LSU sharing and all service latencies are assumptions, without physical NVIDIA calibration.
